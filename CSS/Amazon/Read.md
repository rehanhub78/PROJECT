# Amazon Homepage Clone
This project is a static front-end clone of the Amazon.com homepage built using HTML and CSS. It recreates the core visual structure of the site, including the main navigation bar, hero banner, product grid, and detailed footer.
## Features
 * **Header & Navigation:** Includes a customized logo space, location selector, search bar with a category dropdown, language selector, and a cart icon. Hover effects trigger a transparent-to-white border transition on navigation items.
 * **Secondary Panel:** A sub-navigation menu featuring quick links such as "Today's Deal," "Customer Service," and "Gift Cards".
 * **Hero Section:** A primary banner area styled with a background image that features a promotional message directing users to the Indian Amazon domain.
 * **Product Grid:** An 8-box shop section displaying various product categories (e.g., Gaming, Fashion, Personal Care). The layout utilizes CSS Flexbox for an even distribution of the cards.
 * **Detailed Footer:** A comprehensive 4-panel footer that includes a "Back to Top" button, multi-column site links, a centered logo, and copyright information spanning 1996-2026.
 * **Iconography:** Utilizes FontAwesome via CDN to render UI elements like the magnifying glass, location dot, and shopping cart icons.
## Technologies Used
 * **HTML5:** Used for semantic page structure and content mapping.
 * **CSS3:** Used for styling the application, heavily utilizing Flexbox for layout alignment, spacing, and hover effects.
 * **FontAwesome (v7.3.0):** Integrated for scalable vector icons.
## Setup & Installation
To run this project locally on your machine:
 1. Clone this repository.
 2. Ensure that both your HTML file and the style.css file are located in the same root directory.
 3. **Add Missing Assets:** To render the site exactly as intended, you will need to add your own placeholder images to the same folder. The CSS and HTML code references the following specific file names:
   * amazon_logo.png (Referenced for the header and footer logos).
   * Flag-Logo.jpg (Referenced in the navigation language selector).
   * banar.jpg (Referenced for the hero section background).
   * box-1.jpg through box-8.jpg (Referenced as inline background images for the product category boxes).
 4. Open the HTML file in any modern web browser to view the clone.
